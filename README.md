# Bakim Modu Sitesi

Bu klasor GitHub Pages uzerinden yayinlanabilecek statik bir bakim modu sayfasi icerir.

## Dosyalar

- `index.html`: Ana bakim sayfasi.
- `404.html`: Bilinmeyen adresleri ana sayfaya yonlendirir.
- `.nojekyll`: GitHub Pages'in Jekyll islemesini devre disi birakir.

## GitHub Pages yayinlama

1. Bu dosyalari GitHub reposuna gonderin.
2. GitHub'da `Settings > Pages` bolumune girin.
3. Source olarak ilgili branch'i ve root klasoru secin.
4. Domain icin repo kokune `CNAME` dosyasi ekleyin ve icine sadece domain adini yazin.
